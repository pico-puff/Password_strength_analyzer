# 🔐 Password Strength Analyzer

A simple Python program that evaluates the strength of a password based on common security criteria.

## Features

- Checks if the password is at least 8 characters long
- Detects uppercase letters (A-Z)
- Detects lowercase letters (a-z)
- Detects numbers (0-9)
- Detects special characters (!@#$%^&*)

## Strength Levels

| Score   | Strength |
|---------|----------|
| 0 - 2   | Weak     |
| 3 - 4   | Medium   |
| 5       | Strong   |


## Requirements

- Python 3.x

## Run

```bash
python main.py
```

## Concepts Used

- Python Input/Output
- Regular Expressions (`re`)
- Boolean Logic
- Conditional Expressions
